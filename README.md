# 元书输入法内置键盘

## 候选字筛选面板

输入时点横向候选栏右侧的展开键即可打开筛选面板；启用滑动分页时也可下拉打开。Noctua、Gboard、彩虹、胭云、莫吉托使用各自的深浅色配色：候选字（含首选高亮与按压底色）与未展开的横向候选栏保持一致；iOS 版不设面板底色，沿用系统内置背景以衔接 iOS 26+ 顶部圆角区域，Android 纯色版铺各自主题底板色。其他皮肤沿用面板默认样式。

## default

默认键盘

## numeric

默认数字键盘，当键盘皮肤中不设置数字类型键盘时，使用此键盘。

## sbxlm46

声笔 46 键盘

## Gboard

仿 Google 输入法（Gboard）中文键盘的皮肤，含拼音、数字、符号、九宫格数字四种键盘。

## Noctua

以猫头鹰风扇（Noctua）经典的米棕配色为灵感的皮肤，含拼音、数字、符号、九宫格数字四种键盘。
拼音沿用「彩虹」的版面，其余三种沿用「Gboard」的版面。
