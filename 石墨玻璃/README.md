# 石墨玻璃（Glass Slate）

灵感源自元书输入法应用默认「石墨玻璃」主题（月光钢蓝、烟紫与冰川青灰弥散色调，配冰川蓝强调色）。

## 设计特点

- **iOS 26 液态玻璃底板适配**：预编辑区、工具栏、按键区与横向候选栏采用极低不透明度底色，无缝透出系统自带圆角玻璃背景，避免方角硬边。
- **玻璃键帽层次**：键帽采用垂直微高光渐变、0.5pt 细高光描边与柔和阴影模拟磨砂玻璃折射质感；功能键融入烟紫与钢蓝雾面，回车强调态及首选中候选使用标志性冰川蓝（`#5CAEEB`）。
- **深浅双色配齐**：深色模式忠实还原应用「石墨玻璃」暗色观感；浅色模式提供同源「冰晶石墨玻璃」通透浅色方案。
- **全设备与常用布局**：支持 26 键拼音与数字键盘，覆盖 iPhone 横竖屏与 iPad 横竖屏 / 浮动模式；支持按键上划、长按符号网格、中英切换及预编辑次选上屏。
